# Lens: cpu-microopt (217 techniques)

Instruction-level savings, inlining, code size, memory-level parallelism, prefetch, arithmetic tricks.

Format: `id | title | principle (first sentence)`. The id prefix names the cards file: `../cards/<prefix>.md`.
